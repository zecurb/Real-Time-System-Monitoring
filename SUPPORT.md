# Support

This repository is a source-visible proprietary portfolio project. It is not a managed service and does not include an uptime or response-time commitment.

## Questions and defects

Use GitHub Issues for reproducible defects, documentation gaps, and general questions. Include the release version, operating system, database backend, relevant configuration with secrets removed, and minimal reproduction steps.

## Security reports

Do not report suspected vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Production use

Organizations evaluating production use must perform their own security, capacity, compliance, and recovery review. Commercial use or redistribution requires a separate written license from the copyright holder.
